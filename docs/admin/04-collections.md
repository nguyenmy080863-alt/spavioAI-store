# Collections

Open **Products → Collections**.

A collection groups products so the shop can show a section with all of them. Today the four categories (Skincare Devices, Hair Removal, Hair Styling & Care, Body & Wellness) are listed with a live product count and a link to their shop page.

> Draft: the **Add collection** button is disabled. Creating and editing collections needs a `collections` table (manual and condition-based collections), and the shop navigation must read from it.
