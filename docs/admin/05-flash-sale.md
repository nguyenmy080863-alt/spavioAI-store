# Flash sale

Open **Discounts → Flash sale**.

Configure the countdown campaign shown on the storefront:
- **Timer duration** and **reset rule** (loop or delay).
- **Fake stock** and initial / maximum **sold %**, with optional live purchase simulation.
- **Product mapping** with a percentage discount or an explicit display price.

The widget is client-side only: **checkout prices are not changed** by the campaign.

> **Legal heads-up.** Fake stock levels, simulated purchases and a countdown that restarts can count as misleading urgency (UWG / EU Unfair Commercial Practices Directive). Use it only with real end dates and real stock. See the legal notes in *Discounts*. For real price reductions use **Discounts** instead.
