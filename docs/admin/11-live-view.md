# Live view

Open **Analytics → Live view**. It is the live monitor: today's sales against yesterday, orders per hour, what needs attention right now and the latest orders, refreshed every 30 seconds. See *Analytics and reports* for the details. Requires migration `0020_analytics.sql` for the live numbers.

The catalogue section below it (the former Overview dashboard) is unchanged:

- **Catalogue tiles:** published products, drafts, low-stock count and stock value (price × stock of published products).
- **Low stock alerts:** products at or below their low-stock threshold, linking to the product.
- **Recent admin activity:** the latest entries from the audit log.
