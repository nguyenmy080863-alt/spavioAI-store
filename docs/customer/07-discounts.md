# Discount codes and offers

## Using a code
1. Open the bag and go to **Checkout**.
2. Press **Have a promo code?**, type the code and press **Apply**.
3. The discount appears in your order summary and the total updates. Press **Remove** to take it off.

If you opened a **share link** (for example from an email or Instagram post), the code is already saved and is applied when you reach checkout.

## Automatic offers
Some offers apply by themselves, for example **free shipping** from a minimum bag value. You will see the discount or "Free" shipping in the summary without entering anything.

## Buy X Get Y
Some offers reward a purchase, for example **buy 2, get 1 free**, or a free gel with a device. Add the required items to your bag and the reward is applied automatically. The cheapest reward item is the one discounted.

## Good to know
- **Offers of the same kind do not stack.** If a better offer already applies to your bag, or a code cannot be combined with it, we tell you your code was not added. Some offers do combine, for example free shipping with a code.
- Some codes are only for **first orders**, **returning customers** or **loyal customers**, and **personal codes** only work with the email they were issued to. Use the same email you were given the code for.
- Many codes do **not apply to items that are already on sale** or to **preorders**. The message tells you when a code does not fit your bag.
- Codes can have a minimum spend, a limited number of uses, an end date, or be only for **first orders** or **once per customer**.
- Codes are not case sensitive.
- If you return an item, you get back the price you actually paid for it, after the discount.
