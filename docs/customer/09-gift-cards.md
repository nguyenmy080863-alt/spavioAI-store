# Gift cards

If you received a gift card, you will have a code like `GC-1A2B-3C4D-5E6F-7A8B`.

## Using it
1. Put your items in the bag and go to **Checkout**.
2. Press **Have a gift card?**, type the code and press **Apply**. The summary shows how much of the card will be used.
3. If the card covers the whole order, press **Pay with gift card**. If it covers only part, pay the rest with PayPal. Any value left stays on the card for next time.

## Good to know
- One gift card can be used per order. Gift cards can be used on several orders until the balance is gone.
- Gift cards cannot be exchanged for cash. Keep the code safe: anyone who has it can use it.
- If an order paid with a gift card is cancelled or returned, the value goes back to the card.
- Gift cards are used after discounts and include shipping costs.
- If the code does not work, contact us and tell us the code.
